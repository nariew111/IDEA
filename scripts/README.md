# Workflow scripts

`run_toy_idea_design.sh` runs the small prepared-feature selection example from
any current directory. `OUT_DIR` selects its output directory; `PYTHON_BIN`
selects the Python interpreter.

The IDEA-GP argument template is in `configs/idea_gp.example.sh`.
Study-specific benchmark and figure scripts are tracked in the reproduction
status document at `docs/manuscript_reproducibility.md`.
